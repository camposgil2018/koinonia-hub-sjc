# Roadmap

- [x] Permitir que o perfil de Liderança edite escalas existentes.
- [x] Melhorar a visualização das escalas no celular.
- [x] Equipe (liderança não-admin) não pode excluir escalas — só ver e confirmar.
- [x] Membro pode editar e remover a própria indisponibilidade.
- [x] Totais de mídia refletem todos os pedidos; usuários veem pedidos solicitados ou atribuídos a eles.
- [x] Restringir o estado compartilhado e validar alterações permitidas de cada membro.
- [x] Proteger telefones e e-mails de perfis, mantendo um diretório seguro para escalas.
- [x] Limitar a leitura de papéis ao próprio usuário e à liderança.
- [ ] Corrigir o erro de ambiente/autorização ao excluir um membro.
- [ ] Validar a exclusão com sessão administrativa no fluxo real.
- [ ] Arquivar automaticamente avisos cuja data já passou.
- [ ] Exibir avisos ativos e arquivados separadamente.
